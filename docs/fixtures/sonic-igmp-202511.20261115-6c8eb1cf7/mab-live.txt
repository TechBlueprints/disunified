# kept; its Request Authenticator is written in 4-byte groups); each answer
# is the server's datagram as received.
#

#   Ethertype 0x88B5, which no protocol trap matches (ARP requests reached
#   the CPU in both VLANs through their own trap, so they prove nothing).
