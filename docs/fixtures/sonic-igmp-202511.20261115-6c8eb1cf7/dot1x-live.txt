# 802.1X by hand on the DX010 (docs/drivers/sonic.md 11.25), 2026-11-15,
# image igmp-202511.20261115-6c8eb1cf7, empty cage 31 (Ethernet120, ce30)
# in MAC loopback, the installed disunified-l2d paused for the window, the
# deployed bridge running. hostapd 2.11 built on the switch by
# build-hostapd.sh; a second hostapd (driver=none, its integrated RADIUS
# server, EAP-MD5, one test user and a test secret) on 127.0.0.1:18120 as
# the RADIUS server; the supplicant a raw socket on the port's netdev
# sending from a test MAC and reading the looped replies. Scrubbed with
# scripts/sanitize-sonic.py (every MAC remapped).
#
# run_hostapd: the EAPOL trap, the authenticator alone (the port at
#   cpu_trap, hand-made ebtables rules), a good and a wrong password,
#   hostapd's station list and its events.
# run_guard: the candidate l2d.py's Dot1xGuard driving it (the port at
#   drop; guard.py: sync, show, a second guard as an l2d restart, logoff,
#   teardown).
# run_logoff: the authenticator alone again: a good password, hostapd's raw
#   STA-FIRST / STA-NEXT replies, an EAPOL-Logoff, the events.
#
# After the scrub, 02:00:00:00:00:03 is the host that authenticates and
# 02:00:00:00:00:01 the one with the wrong password; 02:00:00:00:00:02 is
# the switch itself (hostapd hears its own frames come back round the loop
# and makes a station of them; on a cabled port it would not).
